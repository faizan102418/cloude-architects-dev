Sprint Deliverables & Workflows

Key automated deployment systems authored for the ShipIt challenge.

Task A8 · Lead

Pull Request Validation Pipeline

Integrated .github/workflows/check.yml and scripts/check-site.sh. Prevents broken code from merging by validating title tags, testing internal links, and enforcing file size thresholds.

on: [pull_request]
jobs:
  validate-site:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: bash scripts/check-site.sh site/
Task A9 · Lead

Continuous Zero-Downtime Deployment

Engineered .github/workflows/deploy.yml and scripts/deploy.sh. On merge to main, code is uploaded via SSH, isolated in timestamped release folders, stamped with commit metadata, and atomically linked to current.

on:
  push:
    branches: [main]
# Strict SSH host check & zero-downtime release
Task A10 · Lead

1-Click Disaster Recovery (Rollback)

Engineered .github/workflows/rollback.yml and scripts/rollback.sh. Allows instant manual rollback from the GitHub Actions UI, reverting the live symlink to the previous stable release within 5 seconds.

on:
  workflow_dispatch:
# Point /current back to prior stable release
