Task A8 · Lead
🛡️

Pull Request Validation Pipeline

Engineered .github/workflows/check.yml and integrated with scripts/check-site.sh. Blocks bad merges before they hit production by validating HTML titles, checking broken internal links, and enforcing a 1MB file size ceiling.

.github/workflows/check.yml Ubuntu Runner 
on: [pull_request]
jobs:
  validate-site:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: bash scripts/check-site.sh site/
Task A9 · Lead
🚀

Continuous Zero-Downtime Deployment

Authored .github/workflows/deploy.yml and scripts/deploy.sh. On every push to main, code is safely staged, deployed into timestamped release folders, stamped with git author and commit SHA, linked atomically via current symlink, and pruned to keep 5 newest versions.

.github/workflows/deploy.yml SSH Deployment 
on:
  push:
    branches: [main]
  workflow_dispatch:
# Strict SSH host check & zero-downtime release

🔄

One-Click Disaster Recovery (Rollback)

Engineered .github/workflows/rollback.yml and scripts/rollback.sh. Triggerable directly from GitHub Actions tab. Point the live symlink back to the previous stable release in seconds, log audit trail in deploys.log, and notify the team on Slack.

.github/workflows/rollback.yml Manual Dispatch 
on:
  workflow_dispatch:
# Instantly swaps /current symlink to previous release
